# DataPulse — Smart Analytics Dashboard

A responsive business intelligence dashboard built with **HTML, CSS and JavaScript**.

## ✨ Features

- Responsive professional dashboard UI
- Revenue, orders, profit and customer KPIs
- Interactive revenue chart
- 7 / 30 / 90 day period selector
- Regional sales visualization
- Product performance table
- Product search/filter
- Dark / light mode
- Region selector
- Export interaction
- Mobile-friendly layout

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG charting
- Responsive CSS Grid / Flexbox

## ▶️ Run Locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. No server or external library is required.

## 🎯 Portfolio Purpose

DataPulse is designed as a portfolio project to demonstrate dashboard design, responsive frontend development, data visualization concepts and JavaScript interactions.
